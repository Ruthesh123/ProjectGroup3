# InternLink

## 📌 Project Overview
InternLink is a web-based platform designed to centralize internship and part-time job opportunities for university students.  
Currently, postings are fragmented across multiple sites, emails, and word-of-mouth. InternLink solves this by offering a **single, student-focused portal** with dedicated spaces for **students, employers, and administrators**.

---

## 🛠 Tech Stack
- **Frontend:** React, Vite, React Router, Tailwind CSS  
- **Backend:** Node.js / Express, Firebase (Firestore, Auth, Storage, Cloud Functions)  
- **Email Notifications:** Nodemailer  
- **Testing:** Postman (API testing), JMeter (performance testing)  
- **CI/CD:** GitHub Actions  

---

## 🚀 Setup Instructions

### 1️⃣ Clone the repository
```bash
git clone https://github.com/<your-username>/internlink.git
cd internlink
```

### 2️⃣ Frontend Setup
```bash
cd frontend
npm install
npm run dev
👉 Runs on: http://localhost:5173
```

### 3️⃣ Backend Setup
```bash
cd backend
npm install
```

### ▶️ Run Firebase Emulator
```bash
npm run emulators
```
